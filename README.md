# BinCode 多浏览器控制

## 1.2.0 通用版

140 个独立浏览器环境。每个环境可以自定义名称和入口网址，按编号启动，通过 BinCode 扩展和 MCP 执行任务。新环境默认打开本机起始页。

「一键直连」将全部环境设为下次启动时绕过系统代理。正在运行的浏览器继续使用启动时的设置。

- [通用版完整源码 ZIP](./bincode-browser-control-v1.2.0-generic-source.zip)
- [源码 ZIP 的 SHA-256 校验值](./SHA256SUMS-v1.2.0)

解压后按包内 README 安装依赖和运行。需要 Node.js 22 或更高版本，以及支持通过命令行加载开发扩展的 Chromium。默认控制台地址为 http://127.0.0.1:17410/。
